# English Sentence Builder

**Открыть:** https://ommirus-dev.github.io/english-sentence-builder/

Тренажёр английских предложений с подсказками и объяснениями на русском. Весь сайт — в одном `index.html`, без внешних библиотек и API.

- **Level 1:** сборка из слов, перестановки нажатиями, стрелками и перетаскиванием мышью или пальцем.
- **Level 2:** заполнение пропусков с лишними вариантами.
- **Level 3:** самостоятельный перевод с учётом учебных альтернатив и обычных сокращений.
- 30 конструкций B1–B2 в каждом режиме. Ошибки и открытые ответы возвращаются на повторение.
- Прогресс, незаконченные ответы и очередь повторения сохраняются в `localStorage` отдельно для каждого уровня.

## Публикация по HTTPS

1. Создать на GitHub публичный репозиторий `english-sentence-builder`.
2. Загрузить **index.html** в корень ветки `main` (Add file → Upload files → Commit changes).
3. Settings → Pages → Build and deployment → Source: **Deploy from a branch**.
4. Branch: **main**, folder: **/(root)** → Save.
5. Дождаться ссылки на странице Pages: `https://USERNAME.github.io/english-sentence-builder/`.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

На iPhone/iPad открыть именно HTTPS-ссылку в Safari → Поделиться → На экран «Домой». Локальный HTML в просмотрщике «Файлов» не подходит для запуска приложения.

## Сохранение

Данные хранятся только в браузере на текущем устройстве, автоматически между iPhone, iPad и Mac не синхронизируются. Очистка данных сайта удалит прогресс. При недоступном хранилище приложение работает и показывает предупреждение. Установка на главный экран и вкладка браузера могут иметь отдельные хранилища.

Сайт не использует внешние ресурсы. Гарантированный офлайн-запуск после закрытия не реализован: для этого требуется отдельный service worker, что выходит за ограничение «один HTML-файл».

Level 3 сравнивает с подготовленными учебными переводами, а не с любой возможной английской фразой; несовпадение не доказывает грамматическую ошибку. Для каждой конструкции есть русское правило и пример.

## Проверка

Проверены синтаксис JavaScript, 30 наборов карточек и пропусков, допустимые переводы и сокращения, все 90 ответов и завершение трёх уровней. В отдельном мобильном профиле Chromium проверены touch-нажатия, перестановки стрелками, вставка перед словом, touch-перетаскивание через реальные touch-события, повтор ошибок, сохранение незаконченного и готового ответа после перезагрузки. Размеры 320, 390, 768, 1024 и 1440 px — без горизонтального переполнения. Также подтверждена загрузка и отрисовка в Safari на Mac. Интерактивные сценарии проверены в отдельном профиле Chromium; физические iPhone/iPad не тестировались.
